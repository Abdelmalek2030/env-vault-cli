# env-vault-cli 🔐

A lightweight, zero-dependency command-line utility designed for encrypting, decrypting, and safely syncing local `.env` environment files across engineering teams.

## ✨ Highlights
- **Zero External Dependencies:** Built entirely with native Node.js crypto modules.
- **AES-256-GCM Encryption:** Enterprise-grade authenticated encryption for sensitive keys.
- **CI/CD Ready:** Automated decryption workflows for GitHub Actions and deployment pipelines.
- **Open Source:** Licensed under the MIT License.
